# 🚀 うちゅうラボ

5歳から遊べる、宇宙の教育コンテンツです。[space](https://github.com/syoudai0514/space) の宇宙シミュレーターを元に、子供向けに作り直しました。スマホ・タブレット・PCで動きます。

**▶ 遊ぶ**: https://syoudai0514.github.io/space-lab/

## コンテンツ

### 🪐 たいようけいで あそぶ
本物のN体重力シミュレーション(物理エンジンはspaceと同じ)を、5歳でも遊べるUIに:
- 惑星を**タップするとおはなし**(ぜんぶひらがな)が聞ける
- 惑星を**ドラッグで動かせる** → 軌道がどう変わるか観察
- **じっけんボタン**: 「もくせいをちょーおもくする!」「たいようをかるーくする!」など、押すと重力の働きが目で見て分かる実験+ひらがなの解説つき
- 惑星が太陽に食べられたり飛んでいったりすると、ひらがなで実況
- はやさ3段階(🐢ゆっくり / 🚶ふつう / 🚀はやい)と「もとにもどす」

### 📖 ほしの ずかん
太陽と8惑星のカード図鑑。タップすると、その星のおはなしと豆知識が読めます。

### ❓ うちゅう クイズ
3択クイズ全6問。全問正解で「うちゅうはかせ にんてい!」🏆

## ねらい
- 「重力 = 見えないちからで ひっぱりあう」を、説明ではなく**実験で体感**してもらう
- 惑星の名前・順番・特徴を、遊びながら自然に覚える
- おうちの人が読み聞かせながら一緒に遊べる文章量

## ローカルで動かす

```bash
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## 技術構成
- [Three.js](https://threejs.org/)(同梱、ビルド不要)
- 物理: リープフロッグ積分のN体重力シミュレーション(spaceリポジトリ由来)
- 純粋な静的サイト。GitHub Pagesで公開(mainへのpushで自動デプロイ)
